Marvel & DC catalogs for Stremio

Self-hosted catalog addons. They list titles in watch order; Stremio fills in details, and your other addons provide the streams.

On a Mac?

"Install in Stremio" hands the link to the Stremio desktop app, which has been seen to open without installing anything. If nothing appears, use "Install via Stremio Web", or copy the link and in Stremio go to Addons → + Add addon, paste, Add, Install.

Using AIOStreams?

Add these as Custom addons in AIOStreams. Its own "Marvel Universe" and "DC Universe" addons can't be pointed elsewhere: DC's server is suspended and Marvel's keeps going down.

  1. On your AIOStreams configure page choose I already have a configuration and sign in with your UUID and password. The other starting options create a new setup.
  2. Addons → Installed: switch off Marvel Universe and DC Universe.
  3. Addons → Marketplace: search Custom → Configure → paste a manifest URL → Install. Once for https://kellogs12.github.io/marvel-dc-stremio/dc/manifest.json and once for https://kellogs12.github.io/marvel-dc-stremio/marvel/manifest.json.
  4. Catalogs: check the new ones (tagged New) are switched on.
  5. Save & Install: the card must say Save Configuration with your UUID. Click Save. If saving fails because an addon "has been removed", delete that addon (switching it off isn't enough). If an addon's manifest can't be fetched, switch it off. Then save again.
  6. Reinstall AIOStreams: under Direct Manifest URL click the copy icon. Then in Stremio Web open Addons, uninstall the older AIOStreams, click + Add addon, paste, Add, Install.

More detail and troubleshooting: README on GitHub.
